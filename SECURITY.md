# Security policy

V3 is pre-alpha. No released version is currently supported, and the project is not suitable for production or trading use.

Do not open a public issue containing a vulnerability, credential, private dataset, personal information, provider capture, proprietary strategy, or real result artifact. Until the owner establishes a dedicated public security contact, report suspected vulnerabilities through the existing private project channel and include only the minimum reproducible detail.

The repository's CI and local gates scan tracked source and relevant history for common credential patterns, forbidden private-data formats, and unexpectedly large files. These controls reduce risk but are not a guarantee that source is safe to deploy.

Security reports do not authorize access to third-party systems, production environments, broker accounts, data-provider accounts, or private datasets.
