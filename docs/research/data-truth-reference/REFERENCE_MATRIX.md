# Data Truth / Universe Reference Matrix

## 阅读方式

本矩阵比较的是可验证的抽象、行为和缺口，不回答“把哪个项目搬进 V3”。证据编号指向 [`SOURCES.md`](./SOURCES.md)。V3 decision 只给出“成熟经验 → invariant → 现有 V3 contract recommendation”，不建立第二套架构。

## 总体判定

四个项目各自覆盖一段问题，但没有一个同时提供 V3 所需的 permanent identity、available-time PIT、immutable snapshot、PIT Universe 和 fail-closed capability truth。最可取的不是整体引入，而是组合吸收：OpenBB 的 provider/capability 分层、Qlib 的 calendar/PIT/Dataset 思维、RQAlpha 的中国市场时间事实与边界测试、vn.py 的 symbol/exchange/source normalization；再由 V3 现有 Artifact、Task 和 Control Catalog 把这些经验提升为可证明、不可变、可审计的合同。
