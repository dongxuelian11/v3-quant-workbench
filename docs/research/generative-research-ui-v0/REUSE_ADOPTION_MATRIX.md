## Adoption result

Track M adds no Agent/UI framework and copies no third-party source. It reuses the current V3 active-session evidence projection, permission surface, React renderer and ECharts dependency; it adds a V3-native closed wire schema, strict parser, fixed option builders and renderer registry. PydanticAI remains the existing exact-pinned worker SDK and is wrapped by a Track M L1-only typed proposal seam. Every external system remains outside V3 identity, evidence, truth, admission, validation, permission, execution and publication authority.

## Rejected capability surface

- No arbitrary JSX, HTML, Markdown script, import/component path, CSS/style payload, `eval`, `new Function`, formatter function or model-authored ECharts option.
- No model-authored canonical metric/table/chart values. `CANONICAL_EVIDENCE` resolves only from the verified active-session evidence projection by exact evidence ID and approved selector.
- No formula/expression engine and no financial metric recomputation in Track M.
- No second Agent transport, message store, task lifecycle, truth/admission/validation system or publication authority.
- No live structured-output claim: current delivery proves a typed PydanticAI seam with deterministic `FunctionModel` evidence and an explicitly labeled UI fixture boundary.
