## Frozen adapter boundary

- Input authority: canonical current-main `BacktestRunResult`, an exact `ResultAnalyticsPolicyVersion`, and an optional exact `BenchmarkSeriesVersion`.
- Computation authority: `apps/backend/src/v3_backend/domain/result_analytics/**`.
- View adapter: a Track-L-owned typed Result Lab view model maps canonical decimal strings and typed statuses into ECharts arrays and tables.
- Third parties may inform formulas and presentation, but never provide IDs, hashes, Truth/Admission, benchmark acquisition, or publication state.

## Dependency decision

No Python dependency or lockfile change is admitted for Result Analytics V0. The implementation uses `decimal.Decimal`, `datetime`, and existing V3 canonical hashing. ECharts remains the only direct reused analytics-view dependency.
