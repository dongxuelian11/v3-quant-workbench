## 二、第一阶段：可信研究链修复

### 数据、范围与输入

- 历史成员具有股票池标识、来源和版本，配置显式引用。导入一个股票池不得改变其他项目或全市场范围；覆盖分母使用同一份成员记录。
- 行情可以共享，成员、行业及来源元数据不能隐式互相覆盖。旧文件能够确定归属时迁移，否则保留并明确待归类。
- 数据准备完成后固定本次实际输入：行情及预热区间、交易日历、成员、行业、公告财务、公司行动、基准及相关另类数据。
- 复用不可变分区或必要切片，不为每个任务复制整库，不建立哈希身份链。
- 实验保存输入引用、配置、代码、种子、依赖版本和前置结果。“原输入复现”与“最新数据重算”分开；旧实验回放不得悄悄读取新行情。
- 原输入不足的旧实验保留并说明限制；修正产生新实验，不覆盖旧结果。
- 被模型、候选、每日方案或模拟账户引用的产物展示依赖，不能作为普通缓存清理。

### 计算与结果

- 修通组合构建到回测结果的风险贡献链，分别保存目标权重与实际成交权重。
- 风险估计记录时点、样本范围、有效样本与口径；样本不足显示不可用。因子归因、组合风险贡献、覆盖率和模型重要性分别呈现。
- 核对历史股票范围、公告时间、标签跨界、复权、公司行动、费用、现金持仓、申报数量、停牌涨跌停与未成交原因。
- 回测和模拟账户复用成交规则。保留滑点、历史税费、成交量参与限制及延迟执行压力比较，不新增未经校准的冲击模型。
- 正式研究缺少关键输入时暂停受影响步骤；替代数据或缩小范围必须明确记录。任何模式均不得使用未来信息生成历史信号。
- 默认单次时间切分，候选再做滚动验证；验证集选参，测试集独立。测试结果已被用于后续修改时，记录该区间不再属于未见样本。

### 性能、任务与恢复

- 首屏读取元数据、摘要和有限预览；按列、证券、日期及行组查询，统计与完整导出在后端完成。
- 前端不通过连续拉完所有分页计算统计。图表聚合适应视口，完整数据仍可查询。
- 重读取、导出和计算使用现有后台机制，状态及取消请求保持响应。
- 已确认退出的普通进程即使登记结果失败，也释放运行占用；已有文件支持恢复登记，不盲目重算。
- 数据库不可写或原生进程停止未确认时，如实呈现故障，不伪报完成。
- 恢复与重试复用任务关联，避免重复计算、登记实验或提交依赖步骤。

## 三、第二阶段：日常研究与界面

### 研究项目、每日研究台与选股器

独立项目研究因子、策略、模型、课题或研报；每日研究台引用明确版本的成果。源项目更新时展示差异，由用户采用，不自动替换。

训练配方与模型产物分开。手动运行每日方案时，每月首次按需重训，不自动寻优；重训失败暂停该方案，只有明确选择后才能使用兼容旧模型。

**选股器独立使用，无需先建项目：**

- 首次提供条件、因子、策略三个起点；以后主动进入时恢复方案、草稿和已有结果，显示日期及配置变化。
- 统一成果选择器搜索各项目的因子、策略和模型，显示来源与版本。方案按最近使用、收藏和搜索组织，支持复制、重命名及归档。
- 默认最近完整交易日；研究项目仍保留明确选择研究区间的规则。
- 支持阈值、区间、指标比较、排名、上穿／下穿、连续 N 交易日及近 N 交易日出现信号。简单条件可组成“全部／任一”组，复杂逻辑使用已有公式入口。
- 多因子使用方向与权重表格，默认等权排名评分。方向只应用一次；权重非负且总和大于零，归一化后计算。有效样本不足或因子缺失不能填零评分。
- 默认在应用 ST、上市天数等基础过滤后的股票池计算排名；后续条件不改变参照。可明确切换至前置条件过滤后的范围，不把排名条件自身纳入参照范围形成循环。
- 已有结果的过滤与排序即时反馈；需要新数据或计算时明确点击运行。自动准备必要数据，仍缺失时显示局部预览及无法判断名单。
- 策略默认看候选；选择模拟账户或实际持仓后才计算账户相关信号，不修改实际持仓。
- 顶部显示范围、有效数量和入选数量；单股详情展示命中条件、实际值、排名及贡献。搜索未入选股票能区分范围外、条件不符、排名未达标和数据不足。
- 重复运行提供新增、退出、保留和可比评分变化。只与上次成功完整结果比较，配置变更明确标记。
- “加入自选”默认追加去重、保留备注；替换名单是独立操作。选股与自选为同工作区的两个视图。
- “验证历史效果”默认建立独立课题，也可选择已有项目；记住研究关联，不修改来源成果。
- 每日研究引用固定方案版本；多策略按分配资金合并目标，再应用整体约束，保留现金及无法调整原因。

**采用已认可的选股器视觉方向：**宽表为主，条件可折叠，下方按需展开行情／入选解释，可调高度、最大化或独立打开；AI 侧栏保持用户选择的状态。

### 行情与市场概况

- 行情内部证券列表独立折叠，保存宽度、分类、搜索和选择；收起后图表扩展，不重置视口、指标或画线。
- 移除重复“微盘股”快捷按钮，保留指数目录、搜索、自选及相应导入入口。
- 双图／四图十字线默认独立；证券联动、固定标的、周期和缩放分别控制。
- 滚轮围绕光标时间缩放，拖动查看历史；图表不带动外层页面。价格轴默认自适应，手动调整后保持，双击恢复自动。
- 顶部数值栏显示行情详情，点击 K 线才关联 AI；输入和绘图操作不被全局快捷键抢占。
- 股票、指数、行业／概念分别设置默认模板。新图应用默认，切股保留当前配置；只有主动保存才更新模板，画线不混入模板。
- 指标搜索添加、就地修改；副图可排序和调整高度。保留连续绘图、编辑、撤销重做、锁定、隐藏、删除及导出。
- 常用周期栏默认分时、日、周、月，分钟及自定义 N 日从“更多”添加。固定交易日分组、未完成周期标记和分时均价口径沿用此前规则。
- 保留微盘股 TDX880823 接入与导入路径，不用其他曲线替代，不宣称在线源已验证可用。

**市场概况采用已认可的视觉方向：**

- 主要指数紧凑展示；行业／概念使用等大小热力格与强弱排名。
- 提供当日、近 5／20 交易日强弱，使用来源历史曲线，不用当前成员拼接历史。
- 涨跌分布、成交概况各自注明日期与覆盖；不同周期不混算。
- 点击板块原页展开走势和成员，可进入完整行情或带范围进入选股。
- 概念成员可能重叠，不将概念汇总简单相加当成全市场。
- 缺失保持缺失，刷新不自动打乱正在浏览的列表。

### 设置、自定义与默认行为

设置采用 **Codex 式居中大弹窗**：左侧分类与搜索、右侧内容，窄窗口接近全屏；关闭或按 Esc 返回原现场，内部编辑浮层优先处理 Esc。只有长内容区滚动。

| 分类 | 合并后的行为 |
|---|---|
| 通用 | 干净启动；有任务关闭进托盘、空闲退出；前台轻提示、后台重要系统通知，默认无声音；每天至多检查更新一次，手动下载安装 |
| 外观 | 浅／深／跟随系统；默认沿用现有主题，首次浅色；整体缩放与阅读字号独立，正文默认 14px；表格标准 32px、紧凑 26px；按列统一单位 |
| 工作区 | 导航可排序、固定、隐藏；模块可隐藏、排序和调整大小；布局保存显示偏好，不保存具体旧对象；全局默认、项目可覆盖 |
| 行情与图表 | 模板、周期栏、刷新、多图联动、价格轴、指标与绘图偏好；当前图临时修改不自动覆盖模板 |
| 数据与存储 | 一个数据主目录内部分类，另设新项目默认目录；目录变更不默默迁移旧项目；分类占用和手动缓存清理 |
| 数据源 | 首批免费源、通达信和文件；按数据类别选择，显示能力与覆盖；看盘兼容备用源自动切换，正式研究保持来源 |
| 数据更新 | 默认按需；可开启指定自选或每日方案范围的盘后更新，仅软件运行时执行，不自动发起研究 |
| 计算与任务 | 交互优先／均衡／计算优先；高级并行与线程设置，显示生效值；主动研究优先于定时更新，可调整等待顺序，不越过依赖 |
| 任务历史 | 默认最近 30 天，完整历史手动清理；失败停在受影响步骤，独立任务继续；不因删记录删除实验 |
| AI | 默认模型＋用途覆盖；实际回复与只读工具分别测试；全局偏好＋项目补充；不自动换服务 |
| 研究模板 | 因子处理、成本、约束、验证分别保存预设；新研究复制后独立修改，不影响旧配置 |
| 备份与诊断 | 手动导入导出设置包，不含密钥、会话和研究数据；同名冲突明确处理；本地诊断包可预览、隐藏敏感字段、不自动上传 |

实现初始资源档位采用：交互优先 1 个计算任务／每任务最多 2 线程，均衡 1／4，计算优先 2／4；按机器可用核心数收缩。未支持线程限制的计算明确显示实际限制，不声称控制全部资源。更改作用于后续任务。

快捷键默认：`Ctrl+K` 搜索／命令、`Ctrl+,` 设置、`Ctrl+B` 项目侧栏、`Ctrl+Alt+A` AI 栏、`Ctrl+Alt+L` 当前行情证券列表；图表沿用聚焦后的缩放、撤销及回到最新操作。支持修改和冲突提示。

清理范围只包括可重建且未被使用的缓存；原始行情、研报、实验输入及结果不包含在内。设置包不恢复旧会话或自动改变本机路径。

## 四、第三阶段：AI、研报与本地助手

### 研究 AI 与研报

- 明确执行指令调用真实工具；开放研究先确认一份可编辑方案，随后连续完成依赖步骤，不逐步审批。
- 默认三轮研究、6 组候选、**全方案合计 20 次试参、30 次模型请求**；训练、回测、滚动窗口和压力检验单列预算，不隐藏额外计算。
- 重试请求与重新执行计入预算，缓存复用不重复计数；达到上限保留结果，不自行扩大。
- 代码首次失败保存代码、错误和检查点，形成具体修复方案后确认继续；临时服务失败最多重试两次，认证及参数错误直接显示。
- 会话发送时固定项目和引用，晚到回复仍归原会话；项目切换不混入其他历史。空白引导在首次发送后退出。
- 优先完成单篇量化研报的页码证据、方案确认、真实计算、差异解释和成果保存，再扩展跨报告研究。
- 保留原文复现、适配实验、发布后验证和现实成交检验的区别；订阅只更新目录及可获取原文，不自动阅读或计算。
- OpenUI 使用实际结果与保存方案，历史重开不运行任务；成果可被每日研究引用。

### 本地小模型基础助手

- 放在第三阶段，不阻塞日常体验版。优先现成模型，暂不建设微调流程。
- 承担操作意图、对象查找、选股条件转换、标题与标签整理，不承担复杂研究判断。
- 统一搜索／命令框为入口；普通搜索和功能导航不依赖模型安装。
- 首次启用下载至数据主目录，提前显示体积和运行要求；按需加载，默认闲置 10 分钟且没有请求时释放。
- 明确修改直接更新可撤销草稿，保留未涉及条件；明确运行指令沿用统一研究执行能力。
- 信息不明确时就地简短澄清，超出范围提供手动转交研究助手，不静默在线请求。
- 不把命令框基础操作混入研究聊天；转交后才形成对应会话内容。
- 型号尚未锁定，作为第三阶段的有界选型任务：使用真实中文命令、条件分组、缺失参数和歧义案例比较候选，正确理解优先、资源次之；记录冷启动、连续响应及与研究并行时的占用。未通过实际验证不得报告可用。

## 五、接口、兼容、分工与验收

### 接口与兼容

在 `packages/contracts/src/research.ts` 集中扩展：范围与输入版本、条件分组和成果引用、选股方案及结果状态、设置分类和布局偏好、资源调度参数、AI 服务配置及预算。

- GUI、在线 AI、本地助手复用相同研究操作和任务系统，不新增平行计算平台。
- 旧简单筛选条件转换为等价条件组，旧自选名单不改变成员。
- 旧单一 AI 配置迁移为默认服务；旧设置保留有效值。
- 旧布局提取可兼容的排布和显示偏好，不自动恢复其对象标签。
- 设置优先级为当前视图覆盖、项目覆盖、全局默认；只对支持覆盖的显示项适用。存储、服务和资源配置不混入项目视觉覆盖。
- 从已发布基线开展工作，保留旧工作区与未提交内容。只维护 `docs/V3_REBUILD.md`，不重新清理 GitHub 历史。

### 分工与验收

集中验收包括：
